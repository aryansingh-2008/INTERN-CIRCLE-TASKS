# INTERN-CIRCLE-TASKS

Internship tasks completed for **InternCircle**.

---

## 📌 Track 1: Python Development Tasks

Five Python tasks covering CLI tools, Tkinter desktop apps, and web scraping:

- `task1.py` - Interactive Calculator & Unit Converter (Tkinter GUI)
- `task2.py` - Number Guessing Game & Word Counter (CLI Mini Project)
- `task3.py` - Personal Expense Tracker (CSV File Storage)
- `task4.py` - Web Scraper for Headlines & Quotes (BeautifulSoup)
- `task5.py` - Live Weather App (Tkinter GUI with OpenWeather API)

### Requirements & Run
```bash
pip install requests beautifulsoup4
python task1.py
```

## 📌 Track 2: Full-Stack Web Development Suite

Full-stack development assignments built using **React 18**, **TypeScript**, **Tailwind CSS**, **Node.js / Express**, and **SQLite 3** with a clean, minimal UI inspired by ScamShield:

Located in the [`fullstack-tasks/`](./fullstack-tasks/) directory:

1. **Project 01 – Personal Portfolio Landing Page** (`/portfolio`)  
   Professional developer landing page with terminal window, projects showcase, skills matrix, education timeline, and functional contact form connected to the SQLite backend.

2. **Project 02 – Interactive To-Do List** (`/todo`)  
   Task manager with CRUD, status filters, search, and persistent LocalStorage support.

3. **Project 03 – Responsive SaaS Pricing Cards** (`/pricing`)  
   Dynamic pricing cards with monthly/yearly billing switch, discount calculation, and checkout modal.

4. **Project 04 – Live Weather Dashboard** (`/weather`)  
   Real-time global weather search, detailed metrics (humidity, wind, pressure), and 5-day forecast via Open-Meteo REST API.

5. **Project 05 – Interactive Quiz & Mini E-Commerce App** (`/quiz`, `/shop`)  
   Web development quiz with instant feedback and a developer mini store with cart, checkout, and persistent SQLite order storage.

### Running the Fullstack Suite
```bash
cd fullstack-tasks
npm start
```
Open **`http://localhost:5000`** in your browser.
